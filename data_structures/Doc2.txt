# Unidade Lógica e Aritmética
A unidade lógica e aritmética é uma das partes principais de um computador, pois é o local que os dados são processados. A ULA recebe os dados, executa uma ação lógica ou aritmética e retorna o resultado final.

### Controle Hardwired
A unidade de controle hardwired gera as microinstruções a partir de circuitos sequenciais, isto é, as instruções são implementadas em hardware selecionadas por meio de um decodificador. Isso faz com que a complexidade do controlador seja aumentada, pois instruções complexas devem ser "escritas" de maneira física através de portas lógicas. Por ouro lado, essa solução normalmente é a mais rápida para a decodificação de instruções.
### Controle micro programado 
As instruções à serem decodificadas estão salvas dentro de uma memória ROM, chamada de memória de controle, em que seu conteúdo é composto pelas micro instruções que o computador vai utilizar. Essa abordagem facilita a escrita de instruções complexas, pois seu conteúdo fica guardado em uma memória dedicada, não aumentando a complexidade do hardware que vai vai fazer o acesso, no entanto é mais lenta pois o controlador deve fazer a busca nessa memória. 
# Acumulador
O acumulador é um tipo de registrador que armazena o resultado do processamento realizado pela ULA. Após o acumulador, os dados serão enviados para o dispositivo de saída do computador. 
# Registrador de Dados de Memória
Armazena de forma temporária os dados e o código do comando a serem enviados para a ULA. A quantidade de bits que esse registrador consegue armazenar está limitado ao barramento de dados do processador
# Registrador de Endereços de Memória
Armazena, também de forma temporária um endereço de acesso a uma posição da memória do computador, essa memória pode ser RAM ou ROM.
# Memória
Mesmo fora da CPU, a memória é essencial para o funcionamento do computador, pois tanto os dados quanto as instruções estão presentes na memória. Seus dados são acessados por endereços presentes no MAR
# Contador de Instruções
O IC te, trabalha com o sequenciamento das instruções que vão ser enviadas para a CPU, ele registra  incrementa endereços de memória que contém as instruções do programa e envia para o MAR.

# Clock
O Clock do computador é o que define o tempo de execução das instruções e a sincronia dos componentes internos do computador. 

É importante não confundir o clock com o ciclo do computador, pois o ciclo é composto de varios ciclos do clock

# Barramentos
O barramento é em geral o caminho que os dados trafegam até chegar em um componente 
interno ou externo da CPU, é o barramento que determina a quantidade e o fluxo dos dados dentro de um computador. Existem três tipos de barramentos que serão explicados a diante:

## Barramento de dados
Faz o papel de interligar o MDR com a memória principal para a transferência de instruções ou dados a serem executados.

## Barramento de endereços
Interliga o MAR à memória principal, sendo responsável pelo trafego dos endereços de memória requisitados pela CPU até a memória.

## Barramento de sinais de controle
Envia e recebe sinais entre a CPU e os demais componentes do sistema computacional, como dispositivos de entrada e saída.
